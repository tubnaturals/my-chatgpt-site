TUB NATURALS WEBSITE
===================

Files:
- index.html     Home page
- about.html     Scott "The Unlikely Beekeeper" story
- contact.html   Contact information
- styles.css     All design styles
- script.js      Mobile menu + subtle scroll animations

HOW TO USE
1. Keep all five files in the same folder.
2. Double-click index.html to preview the site locally.
3. Upload the folder contents to your web host when ready.
4. To edit wording, open the .html files in any text editor.
5. To change colors/fonts/layout, edit styles.css.
